# 토닥토닥 한글 타자 숲

초등 5학년 수준에 맞춘 건전하고 재미있는 한글 타자 연습 웹 게임입니다.

## 주요 기능
- **문장 따라치기**: 위에 뜨는 5학년 교과서(우리말·속담·과학·역사) 문장을 보고 아래 칸에 똑같이 입력하는 연습
- **낱말 톡톡 게임**: 하늘에서 내려오는 5학년 필수 낱말을 풀밭에 닿기 전에 잡는 미니게임
- **오타 먹구름 대작전**: 정확한 타자 공격으로 장난꾸러기 오타 먹구름 보스를 물리치는 배틀 모드
- **60초 타임어택**: 1분 동안 콤보와 피버 타임(점수 2배)으로 최고 기록에 도전
- **한글 두벌식 자판 도우미 & 효과음**: 다음 키 안내와 Web Audio API 기반 경쾌한 효과음 지원
- **칭찬 스티커 도감 & 성장 기록**: 12종의 칭찬 스티커 수집 및 브라우저 로컬 저장

## 실행 방법

```bash
npm install
npm run dev
```

## 프로덕션 빌드

```bash
npm run build
```
